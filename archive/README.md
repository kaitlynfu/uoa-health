# Project archive

`legacy-demos/` contains the old browser app prototypes. FastAPI no longer
serves `/demo/*`; the supported app is in `frontend/`.

`legacy-backend/scraper_service.py` is an unused earlier scraper, superseded by
`backend/app/services/scraper/`. These archived files are reference only and
are not included in backend releases. Current AR tools and the printable
`docs/home-start-marker.html` remain in the active app/documentation.

[Development records](development-notes/README.md) preserve superseded root-level handover notes and the September deployment guide. Their historical status statements do not describe the current application.
